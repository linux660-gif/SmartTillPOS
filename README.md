# SmartTillPOS

## Phase 1

### Python

#### Requirements

- Python 3.10.+
- IDE / CMD / Terminal

#### How to Run 

Run from terminal/Command Prompt

- Windows: `python \path-to-the-downloaded-code\main.py`
- Linux/ MacOS (Unix): `python3 /path-to-the-downloaded-code/main.py`

### Java 

#### Requirements

- Java sdk (openjdk 21.0.11 or later)
- Java Extension Pack(Vs Code) or Use JetBrains IDE for Java

### C++

#### Requirements
- g++ Compiler or any suitable c++
- c++ 11 or Later

#### How to Run

Assumming g++ compiler

- Make an executable file: `g++ main.c++ -o main`
- Run the Executable program: `./main`

### JavaScript 

#### Requirements

- Browser 

#### How to Run

Double Click the `main.html` file to see the results
