### Project Setup and Review
1. Java (inventory, sales,payment)
 - Version 21
 - Build tool: `Maven`
 - Framework: `Springboot`
 - Testing: `JUnit`
 - Structure: `start.spring.io`
 - Dependencies: `pom.xml `
 - Checklist: `java installed, Maven installed(wrapper), project structure, required dependecy in pom.xml`
2. Python (employees, suppliers, reports, apigateway,)
 - Version 3.12 ^
 - Build tool: `pip`
 - Framework: `fastapi`
 - Testing: `pytest`
 - Structure: As in the repo
 - Dependecies: `requirements.txt`
 - Checklist: `python installed, fastapi familiar, using venv(virtual env), project structure,`
3. C++ (Receipts)
  - Version c++20
  - Build tool: `make`
  - Framework: `null`
  - Testing: `Google tests`
  - Structure: As in the repo
  - Dependencies: `CMakeList.txt`
4. JavaScript (UI)
 - Version: `React 19.3`
 - Build tool: `npm`
 - Framework: `ReactJs & Typescript`
 - Testing: `vitest`
 - Structure: `intermediate react project structure`
 - Dependencies: `package.json`
